# QA-Portfolio

Портфолио начинающего QA-инженера. Здесь собираются тест-кейсы, баг-репорты и — по мере продвижения — автотесты, документация и CI/CD-настройка. Всё пишется и заливается по ходу реального обучения, без прошлого опыта в индустрии — рост виден прямо по истории коммитов.

## О чём этот репозиторий

Прохожу путь от основ ручного тестирования до автоматизации на Playwright + Python. Каждый этап обучения оставляет здесь конкретный артефакт: не абстрактные конспекты, а реальные тест-кейсы и баги, найденные на живых сайтах.
